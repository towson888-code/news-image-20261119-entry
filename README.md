# World News — 19 November 2026

A program that writes one image summing up the world news of
**Thursday, 19 November 2026** — a newspaper front page with seven
verified stories: the first Trump–Xi–Putin trilateral summit in Shenzhen,
Ukraine's third strike on the Kerch Bridge in a week, the world court's
Myanmar genocide ruling, Anthropic's record IPO, Israel's push into central
Gaza, unrest in Bangladesh, and Denmark's Greenland vote.

Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes exactly one image, `entry.png` (1024×1024), to the output
directory. No network, no clock, no randomness — two runs write
byte-identical output.

Entry for the [make.fun bounty](https://make.fun/bounty/news-image-20261119).
